# 用参数与逐元素账本理解SwiGLU的宽度预算

把普通前馈层改成SwiGLU时，多了一条学习到的投影路径。若仍沿用原隐藏宽度，参数和矩阵乘法规模也会增加；比较激活设计前，需要先说明宽度与预算是否匹配。

## 三个矩阵分别做什么

采用行向量约定，输入 $x\in\mathbb R^D$。普通无偏置前馈层为 $\phi(xW_1)W_2$，其中 $W_1\in\mathbb R^{D\times F}$、$W_2\in\mathbb R^{F\times D}$，参数数目 $2DF$。

SwiGLU改为

$$g=xW_g,\quad u=xW_u,\quad a=\operatorname{SiLU}(g)\odot u,\quad y=aW_d,$$

其中 $W_g,W_u\in\mathbb R^{D\times H}$、$W_d\in\mathbb R^{H\times D}$，$\operatorname{SiLU}(z)=z\sigma(z)$、$\sigma(z)=1/(1+e^{-z})$，$\odot$为对应元素相乘。$g,u,a$都长H，总参数为 $3DH$。多出来的投影不是一份可直接删除的重复矩阵：它与另一条投影相乘，改变函数族。

这里只比较无偏置的数学层。带偏置时，普通层另有 $F+D$ 个参数，SwiGLU另有 $2H+D$，应按实际架构重算；也不把参数数目等同于训练峰值内存或实测速度。

## 为什么常见的宽度约为普通层的三分之二

匹配矩阵参数量需要 $3DH=2DF$，故 $H=2F/3$。如果原层 $F=4D$，则 $H=8D/3$。例如 $D=6,F=24,H=16$ 时，两者都含288个矩阵参数。

硬件对齐常使整数宽度略偏离精确等式。假设 $D=4096,F=16384$，并**自行规定向上对齐到256的倍数**，则理想 $H=32768/3$，对齐后 $H=11008$：

| 层 | 宽度 | 矩阵参数数目 |
| --- | ---: | ---: |
| 普通前馈层 | 16384 | 134217728 |
| SwiGLU，向上对齐 | 11008 | 135266304 |

比值为129/128，多0.78125%。这是明确对齐规则下的算术例子，不是声称所有模型或实现都采用同一规则。矩阵参数相近时，额外逐元素激活与乘法、内核融合和通信仍可能不同；不能由这个比值直接给出运行时间。

## 两维输入的完整前向过程

令 $D=H=2$，$x=(1,-1)$，

$$W_g=I_2,\qquad W_u=\begin{pmatrix}2&3\\0&0\end{pmatrix},\qquad W_d=I_2.$$

于是 $g=(1,-1)$、$u=(2,3)$。记 $q=e/(1+e)$，则 $\operatorname{SiLU}(g)=(q,-1/(1+e))$，逐元素乘后输出

$$y=(2q,-3/(1+e))\approx(1.46211716,-0.80682426).$$

SiLU的输出可为负，所以“门”不是0到1之间的保留概率；只有其内部的sigmoid在这个区间。两条路径的输出要按同一隐藏坐标相乘，不能把 $g^Tu$ 的一个标量当成这个H维结果。

反向时，若传到a的梯度为v，则传到u的梯度为 $v\odot\operatorname{SiLU}(g)$，传到g的梯度为 $v\odot u\odot[\sigma(g)+g\sigma(g)(1-\sigma(g))]$。输入梯度再经两份投影相加，不能只沿门分支反传。

## 同时沿门投影和线性投影回传的完整梯度

沿本例取 $L=y_0+y_1$，因此传到a的梯度为 $(1,1)$。记 $q=\sigma(1)$、$t=1-q=\sigma(-1)$，则 $\operatorname{SiLU}'(1)=q+qt$，$\operatorname{SiLU}'(-1)=t-tq=t^2$。

| 对象或路径 | 完整梯度 |
| --- | --- |
| 对g | $(2(q+qt),3t^2)$ |
| 对u | $(q,-t)$ |
| 经 $g=xW_g$ 回到x | $(2(q+qt),3t^2)$ |
| 经 $u=xW_u$ 回到x | $(2q-3t,0)$ |
| 对x合计 | $(4q+2qt-3t,3t^2)$ |

本例u的第二分量为3，是因为 $u_1=3x_0$，而不是它独立于输入。即使 $W_u$ 第二行为0，第一维输入仍同时影响两个u分量，所以不能省去 $(2q-3t,0)$ 这条路径。

A直接以 $L(x)=\operatorname{SiLU}(x_0)\,2x_0+\operatorname{SiLU}(x_1)\,3x_0$ 构造独立标量函数，对x=(1,−1)的两个坐标作中心差分；步长 $10^{-6}$，最大绝对误差小于 $10^{-8}$。每次扰动都重新计算g和u，没有冻结u；这仅验证教学函数导数，没有运行模型训练。

练习：若保持普通层 $F=4D$，SwiGLU也取 $H=4D$，无偏置矩阵参数量变成原来的多少？答案：$12D^2/(8D^2)=3/2$。这不是匹配参数量的对照。若本例将u人为设为零向量，输出为零，但对u的局部导数一般不为零；输出值与敏感度是不同概念。
