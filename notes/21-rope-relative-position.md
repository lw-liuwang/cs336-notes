# 用二维旋转推导RoPE的相对位置与缓存偏移

注意力的点积同时需要内容相似性和位置信息。RoPE把每个 query/key 的成对坐标按位置旋转，使一对位置进入点积的方式只依赖位置差。本篇从一个二维平面推导，再说明多个平面、共同平移和缓存位置的边界。

## 固定旋转约定，避免位置差的符号混乱

定义逆时针旋转矩阵

$$R(\phi)=\begin{pmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{pmatrix}.$$

位置 $m$ 的列向量 query 为 $q_m'=R(m\theta)q$，位置 $n$ 的 key 为 $k_n'=R(n\theta)k$。由于 $R(\phi)^T=R(-\phi)$ 及旋转的复合性质，

$$(q_m')^Tk_n'=q^TR((n-m)\theta)k.$$

在这个列向量和逆时针约定下，差为 $n-m$。采用其他行向量或旋转约定时式子可写成另一符号，但不能只改符号而不同时改旋转定义。这里的 $q,k$ 表示同一对固定的未旋转内容向量，不是声称不同位置的真实内容向量都相等。

## 一个完整的四分之一圈算例

取 $q=(1,2)^T$、$k=(3,4)^T$、$\theta=\pi/2$，选择 $m=1,n=2$：

| 对象 | 计算 | 结果 |
| --- | --- | --- |
| query旋转 | $R(\pi/2)q$ | $(-2,1)^T$ |
| key旋转 | $R(\pi)k$ | $(-3,-4)^T$ |
| 直接点积 | $(-2)(-3)+1(-4)$ | 2 |
| 相对式 | $q^TR(\pi/2)k=(1,2)\cdot(-4,3)$ | 2 |

若共同平移3个位置，变成 $m=4,n=5$，旋转后向量分别是 $(1,2)^T$、$(-4,3)^T$，点积仍为2。若仅交换位置差为 $n-m=-1$，相对式变成 $(1,2)\cdot(4,-3)=-2$；位置顺序不能省略。若 $m=n$，点积恢复 $q^Tk=11$。

旋转保持单个向量的范数，本例分别为 $\sqrt5$ 和5。因此点积绝对值始终不超过 $\sqrt{125}$。保持范数并不意味着点积不变：两个向量在不同位置转过不同角度，夹角改变。

## 多个二维平面组成一个注意力头

若头维度 $d$ 为偶数，可将坐标分成 $d/2$ 对，第 $j$ 对使用频率 $\theta_j$。原始常见参数化为 $\theta_j=10000^{-2j/d}$，$j=0,\ldots,d/2-1$。总点积是各二维平面相对旋转点积之和：

$$\sum_{j=0}^{d/2-1}q_j^TR((n-m)\theta_j)k_j.$$

不同频率让同一位置差在不同平面上表现不同相位；具体基数、频率缩放和长上下文扩展属于额外设计，不能从上式直接得出任意上下文长度都可靠。此处的二维例子用 $\pi/2$ 方便手算，并不是把原参数化第一项的1弧度偷偷替换为论文默认值。

相对式也不保证任意固定 $q,k$ 的注意力分数随距离单调下降。本例位置差0时为11，差1时为2，差4时又为11，周期性给出直接反例。实际 attention 还包括缩放、softmax、内容向量和掩码，不能把一个原始点积误读成最终注意力概率。

## KV缓存必须保留一致的位置坐标

如果缓存保存的是已经旋转的 key，就应保留它原来的位置相位；新 query 使用同一坐标体系中的当前位置。以缓存 key 的位置 $n=1$、新 query 的位置 $m=2$ 为例，相对差为-1，分数应为-2。若每次解码都错误地把新 query 位置重置为0，而旧 key 仍在1，差变为+1，分数变为2。

这不表示必须永远使用某个绝对原点。若同时对全部参与点积的 query/key 坐标减去同一偏移，数学上的相对差保持不变；已经旋转的缓存则必须作一致转换，不能只修改新 query 的编号。还需确保因果掩码、滑动窗口和输入的 position id 使用兼容的坐标；RoPE本身不阻止一个 query 读取未来或其他文档。

## 四维两平面的点积可以下降后再恢复

为把高维求和具体展开，另取教学频率 $\theta_0=\pi/2$、$\theta_1=\pi/4$，固定 $q=k=(1,0,1,0)^T$，按相邻坐标分成两个平面。记位置差 $d=n-m$，每个平面均从 $(1,0)$ 开始，所以两个贡献分别为 $\cos(d\pi/2)$ 与 $\cos(d\pi/4)$。

| 位置差d | 第一平面贡献 | 第二平面贡献 | 总点积 |
| --- | ---: | ---: | ---: |
| 0 | 1 | 1 | 2 |
| 1 | 0 | $\sqrt2/2$ | $\sqrt2/2$ |
| 2 | −1 | 0 | −1 |
| 4 | 1 | −1 | 0 |
| 8 | 1 | 1 | 2 |

例如d=4时，第一平面已转完整一圈、第二平面转半圈，贡献相互抵消；d=8时两个平面均恢复初始相位。总点积从2降到−1又恢复到2，直接反驳“距离越远，固定内容点积一定越低”。这里 $\|q\|=\|k\|=\sqrt2$，表中绝对值也均不超过2。

共同平移只改变m、n本身，保持d不变，故每个平面和总和均保持。A分别用m=0、3、9及n=m+d直接旋转四维向量，再与表中相对式交叉核对，绝对误差小于 $10^{-12}$。这些频率为便于手算而选，不能用该周期表推断原论文频率或实际模型的长上下文表现；未运行模型实验。

练习：固定本例内容向量与频率，位置从 $(m,n)=(1,2)$ 改为 $(6,7)$，分数是多少？若只将query位置从1改为2而key仍在2呢？答案：共同平移后仍为2；第二种差为0，分数为11。前者验证相对位置性质，后者改变了相对位置。
